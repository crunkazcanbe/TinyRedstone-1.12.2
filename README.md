# Tiny Redstone for Minecraft 1.12.2

A backport of **[Tiny Redstone](https://github.com/dannydjdk/Tiny-Redstone)** by **dannydjdk** to
**Minecraft 1.12.2** (Forge / Cleanroom), made for the Pride modpack.

Build whole redstone circuits **inside one block**: place a **Redstone Panel**, then put tiny redstone
components on its 8×8 grid. Tiny circuits behave like full-size redstone, and panels talk to the world and to
each other through their edges.

## What's in it
- **Redstone Panel**: the board everything goes on (right-click with dye to recolour it).
- **Tiny components:** redstone dust (pick which sides connect), repeater (1–4 ticks), redstone torch / NOT gate,
  comparator (with subtract mode), piston + sticky piston (push up to 12 tiny blocks, even onto a neighbouring
  panel), observer, redstone block, redstone lamp (lamps add up their light), wooden + stone buttons,
  solid + transparent tiny blocks.
- **Logic Gate cell**: one configurable gate, styled after Project Red gates (torch + chip look).
- **Block Chopper**: make tiny blocks out of almost any block texture.
- **Wrench** to rotate panels / remove components, **Color Selector** for tiny blocks.
- Silicon + silicon compound crafting items.

## Download
See **[Releases](../../releases)**. Drop the jar into a 1.12.2 Forge or Cleanroom `mods/` folder.
